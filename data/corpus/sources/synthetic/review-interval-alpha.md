# SYNTHETIC: Routine review interval memo Alpha

SYNTHETIC TRAINING DOCUMENT. Project-authored on 2026-10-03, version 1.
This is a deliberately fictional reference for the Kestrel training service.
It contains no real patient data and must not be used to schedule clinical care.

## Scope

This memo concerns the routine review of a completed documentation exercise.
It does not concern a patient follow-up visit, treatment duration or medicine
schedule. The service and rule are invented for corpus evidence testing.

## Stated interval

Within the fictional Kestrel training service, the routine documentation review interval is 7 days.

The interval is a source statement, not a calculation. This memo supplies no
exception list, alternative interval, precedence rule or external authority.
It is not marked as superseding another memo.

## Review record

A training reviewer attributes the stated interval to this memo by its title
and version. If another source gives a different interval for the same scope,
both statements must remain visible. File order, upload order and filename
sorting do not establish which source controls.

## Limits

This document is one side of a controlled synthetic disagreement. It provides
no medication, contraindication, interaction or individual care recommendation.
It is corpus content only; it is not a question-answer evaluation case or an
instruction for the application to ignore other evidence.
